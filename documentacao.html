Pipeline de dados com PostgreSQL + MySQL, geração de gráficos e envio de relatório por e-mail

Visão Geral

Pipeline Python que extrai dados de vendas de dois bancos de dados distintos (MySQL — Empresa 01 e PostgreSQL — Empresa 02), consolida os dados, gera um gráfico comparativo de vendas por ano em escala logarítmica e envia o relatório automaticamente por e-mail com o gráfico em anexo.

Módulos

projeto01.py — Script Principal

Orquestra o pipeline completo em sequência:

  1. Conecta ao PostgreSQL e MySQL usando variáveis do .env
  2. Executa query no MySQL: agrega valor_venda por ano (tabela datadt_curso_python.vendas)
  3. Executa query no PostgreSQL: agrega valor por ano (tabela vendas.nota_fiscal)
  4. Concatena os dois DataFrames e cria tabela pivot por empresa
  5. Gera gráfico de barras em escala logarítmica e salva como grafico_vendas.png
  6. Envia relatório por e-mail via EmailSender
  7. Fecha as conexões no bloco finally

Queries SQL

-- MySQL (Empresa 01)
SELECT data_venda, valor_venda
FROM datadt_curso_python.vendas

-- PostgreSQL (Empresa 02)
SELECT 'Empresa 02' AS empresa,
       date_part('Year', data_venda) AS ano,
       sum(valor) AS total_vendas
FROM vendas.nota_fiscal
GROUP BY date_part('Year', data_venda)
